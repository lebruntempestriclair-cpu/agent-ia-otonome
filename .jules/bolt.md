## 2025-05-22 - Pre-rendered JSON for Health Check
**Learning:** Pre-rendering JSON responses to bytes during application startup for static or semi-static endpoints (like `/health`) eliminates the overhead of Pydantic validation and JSON serialization on every request. This is particularly effective for high-frequency monitoring endpoints. In FastAPI, returning a raw `Response` object bypasses the standard response pipeline but can break OpenAPI documentation if `response_model` or `responses` is not explicitly set.
**Action:** Use `json.dumps(...).encode("utf-8")` at module level or during startup for static responses. Return them using `fastapi.Response(content=DATA, media_type="application/json")`. Always use the `responses` argument in the route decorator to preserve API documentation.
