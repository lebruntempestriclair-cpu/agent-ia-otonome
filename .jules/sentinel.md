## 2025-05-15 - [API Security Hardening]
**Vulnerability:** Multiple security weaknesses were identified in the main API entry point: timing attack vulnerability in API key comparison, insecure CORS configuration allowing credentials with wildcard origins, lack of production environment safeguard for default credentials, and swallowed exceptions masking security-related errors.
**Learning:** FastAPI's `CORSMiddleware` will raise a `RuntimeError` at startup if `allow_credentials=True` is used with `allow_origins=["*"]`, making this both a security and stability fix. Broad exception handling in route handlers can unintentionally mask specific `HTTPException` status codes (like 403 Forbidden), converting them to generic 500 errors and complicating debugging and security auditing.
**Prevention:** Always use `secrets.compare_digest` for security-sensitive comparisons. Implement explicit environment checks for default secrets in production. Ensure `HTTPException` is explicitly re-raised before generic `Exception` catches in FastAPI routes.
